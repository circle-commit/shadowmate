# Shadowmate

(예전 이름: Shadowmate, Netflix DualSub)

넷플릭스 영상 위에 두 언어 자막(예: 영어·일본어·스페인어 + 한국어)을 함께 보여 주고 문장 단위 쉐도잉을 돕는 크롬 확장 프로그램. 단어 뜻 찾기는 현재 영어 원어에서 동작합니다.

## 설치

1. 크롬 주소창에 `chrome://extensions` 입력
2. 오른쪽 위 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드합니다** → 이 폴더(`netflix-dualsub`) 선택
4. 넷플릭스 탭이 열려 있었다면 새로고침

코드를 고친 뒤에는 확장 카드의 새로고침 버튼을 누르고 넷플릭스 탭도 새로고침하세요.

## 사용

툴바의 확장 아이콘 → `사용법`을 누르면 기능·단축키 설명과 추천 공부 순서(가리고 듣기 → 다시·느리게 → 확인 → 따라 말하기, `help.html`)가 새 탭으로 열립니다.

자막 언어와 단축키(`A`/`S`/`D`/`Q`/`C`/`W`/`E`/`R`/`T`/`B`/`N`/`H`)는 패널의 `⚙`에서 바꿀 수 있습니다. 단축키는 바꿀 키 버튼을 누르고 새 키를 누르면 바로 저장되고, 다른 기능이 쓰던 키면 서로 맞바뀝니다. `Esc` 취소, `기본값`으로 되돌리기.

| 키 / 버튼 | 동작 |
|---|---|
| `A` / `‹` | 이전 문장 |
| `S` / `↻` | 현재 문장 다시 |
| `D` / `›` | 다음 문장 |
| `H` | 자막 끄기·켜기: 패널을 통째로 숨기고 넷플릭스 자체 자막으로 돌아감. 꺼져 있는 동안 다른 키는 넷플릭스로 감 (기억됨) |
| `R` / 패널 아래 `0.75×` | 지금 문장을 0.75배로 다시 듣기. 문장이 끝나면 누르기 전 속도로 돌아감 |
| `Q` / 패널 아래 `자동 정지` 스위치 | 문장이 끝나면 자동 일시정지 |
| `T` / 패널 아래 `반복` | 문장 반복 횟수: 끔 → 2 → 3 → 5번. 문장마다 그만큼 다시 듣고 넘어감(자동 정지가 켜져 있으면 다 들은 뒤 멈춤). 버튼에 `반복 2/3`처럼 진행 표시 (기억됨) |
| `C` / 패널 왼쪽 아래 복사 아이콘 | 지금 원어 문장을 클립보드에 복사 |
| `B` / 패널 아래 마이크 | 녹음 시작(영상 멈춤) → 다시 누르면 끝내고 원어민 문장 → 내 녹음 순서로 재생. 처음엔 크롬이 www.netflix.com의 마이크 권한을 물어봄(권한은 넷플릭스 사이트에 기록되니 "이번만 허용" 추천) |
| `N` / 패널 아래 `비교` | 방금 녹음한 문장에서 원어민 → 내 녹음 다시 듣기 (녹음한 문장일 때만 버튼이 보임) |
| `W` / 설정의 `원문 가리기` | 원어 자막을 흐리게 가림. 그 줄에 마우스를 올리면 보이고, 자막 목록도 같이 가려짐 (기억됨) |
| `E` / 설정의 `번역 가리기` | 번역 자막을 같은 방식으로 가림 |
| 설정 아이콘 (슬라이더 모양) | 원어 / 번역 자막 언어 (선택은 기억됨), 간단히 보기, 단축키 |
| 설정의 `간단히 보기` | 평소엔 자막 두 줄만 어두운 배경 위에 보이고 패널에 마우스를 올리면 버튼·타이밍 바가 나옴 (단축키는 그대로, 기억됨) |
| 목록 아이콘 | 오른쪽에 전체 자막 목록 (현재 문장 강조, 클릭하면 그 문장으로) |
| 패널 아래 바 | 대사가 나오는 구간. 가운데 선이 지금, 막대를 누르면 그 문장으로 |
| 원어 자막의 단어 클릭 | 영영 뜻 팝업 (Wiktionary) + 네이버 사전 링크. 영상은 잠깐 멈춤, `Esc`·바깥 클릭·다음 문장에서 닫힘 |
| 원어 자막의 여러 단어를 드래그 | 구절·숙어 뜻 (`beat me to the punch` → `beat someone to the punch`처럼 me/my를 someone/one's로 바꿔서도 찾아봄) |
| 패널의 `☆` | 지금 문장 저장 (★ = 저장됨, 다시 누르면 취소) |
| 단어 뜻 창의 `☆` | 그 단어·구절을 뜻·문장·번역과 함께 저장 |
| 툴바의 확장 아이콘 | 저장함: 저장한 단어·문장 목록, 삭제, CSV / Anki 내보내기 |
| 패널의 빈 곳 드래그 | 패널을 원하는 곳으로 옮김 (위치는 기억됨). 빈 곳 더블클릭 = 원래 자리 |
| 패널 오른쪽 위 모서리 드래그 | 크기 조절 (위·오른쪽 = 크게, 아래·왼쪽 = 작게, 0.6~2배, 기억됨). 모서리 더블클릭 = 기본 크기 |

넷플릭스 자체 자막은 이 패널이 떠 있는 동안 숨겨집니다. 넷플릭스의 `S`(오프닝 건너뛰기) 단축키는 이 확장이 가져갑니다.

Language Reactor 같은 다른 자막 확장은 꺼 두세요. 같은 `A`/`S`/`D` 키를 쓰고 화면도 겹칩니다.

## 저장한 단어 내보내기

툴바의 확장 아이콘(퍼즐 조각 메뉴에서 고정해 두면 편해요)을 누르면 저장함이 열립니다.

- **CSV**: 엑셀·구글 시트용. `-`나 `=`로 시작하는 칸은 수식으로 실행되지 않게 앞에 `'`가 붙습니다.
- **Anki**: Anki에서 `파일 → 가져오기`로 받은 `.txt`를 고르면 앞면(단어/문장)·뒷면(뜻·문장·번역)·태그(`dualsub`)가 자동으로 잡힙니다.

저장한 항목은 크롬 확장 저장소에 남아서 넷플릭스에서 로그아웃해도 지워지지 않습니다. 확장을 삭제하면 같이 지워지니 그 전에 내보내 두세요.

## 동작 방식

- `content.js`는 페이지 안(`"world": "MAIN"`)에서 가장 먼저 실행되어 `JSON.parse`를 감싸고, 넷플릭스 플레이어가 받는 영상 정보에서 언어별 자막 주소(`textTracks`, 2026-06 이전 이름은 `timedtexttracks`)를 꺼냅니다.
- 두 언어의 TTML 자막을 받아 파싱하고(`lib.js`), 시간이 겹치는 줄끼리 짝지어 보여 줍니다.
- 넷플릭스는 기본 언어 몇 개만 자막 주소를 주고 나머지는 비워 둡니다. 그런 언어를 고르면 넷플릭스 자막을 잠깐 그 언어로 바꿨다가(그러면 넷플릭스가 주소를 보내 줌) 원래대로 되돌립니다.
- 단어 뜻은 Wiktionary REST API(무료, 키 없음, CC BY-SA)에서 페이지가 직접 가져옵니다. `cities`처럼 사전에 따로 뜻이 없는 변형된 단어는 `city` 같은 기본형으로 찾아봅니다(영어 원어 자막일 때만).
- 저장은 `bridge.js`(확장 쪽 스크립트)를 거쳐 `chrome.storage.local`에 항목마다 따로 들어갑니다. 페이지 안에서 도는 `content.js`는 크롬 확장 API를 직접 못 쓰기 때문입니다.
- 광고 요금제의 중간 광고는 같은 `<video>`에서 재생돼서, 광고가 한 번 나온 뒤로는 영상 시간이 광고 길이만큼 앞서갑니다. 그래서 자막 시간은 넷플릭스의 작품 내 위치(`getSegmentTime`)를 기준으로 맞추고, 광고 중에는 패널을 숨깁니다(배속 확장으로 광고를 빨리 넘겨도 마찬가지).
- 느리게 다시 듣기는 `video.playbackRate`를 바꿉니다. Video Speed Controller(VSC)가 깔려 있으면 VSC가 남이 바꾼 속도를 자기 속도로 되돌려서, VSC의 속도 함수(`window.VSC_controller.actionHandler.adjustSpeed`)로 바꿉니다.
- 녹음은 페이지에서 `getUserMedia` + `MediaRecorder`로 합니다(넷플릭스의 Permissions-Policy가 마이크를 허용함). 마지막 녹음 하나만 메모리의 blob URL로 들고 있다가 다음 녹음·작품 이동 때 지우고, 마이크 트랙은 녹음이 끝나는 즉시 닫습니다. 저장이나 전송은 하지 않습니다.
- 이동/일시정지는 넷플릭스 내부 플레이어 API로 합니다. `video.currentTime`을 직접 바꾸면 넷플릭스가 에러(M7375)를 띄우기 때문입니다.

## 개발

```bash
node --test
```

`dev/saved-harness.html`은 가짜 `chrome.storage`로 저장함 팝업을 띄워 봅니다. `dev/harness.html`은 가짜 넷플릭스 페이지입니다(실제 `<video>` + 가짜 플레이어 API + 가짜 manifest). 프로젝트 폴더를 `python3 -m http.server 8766`으로 띄우고 `http://localhost:8766/dev/harness.html`을 열면 넷플릭스 없이 패널·단축키·자동 일시정지를 확인할 수 있습니다. 테스트 영상은 ffmpeg로 만듭니다:

```bash
ffmpeg -f lavfi -i testsrc=duration=40:size=640x360:rate=25 -f lavfi -i sine=frequency=440:duration=40 -c:v libx264 -pix_fmt yuv420p -c:a aac -shortest dev/clip.mp4
```

아이콘(`icons/`, 파란 타일 위 흰·노란 두 줄)은 macOS에서 다시 만들 수 있습니다:

```bash
swift dev/make-icons.swift
```

## 스토어 출시

등록 글·심사용 문구는 `store/listing.md`, 개인정보처리방침은 `docs/privacy.html`(GitHub Pages)에 있습니다. 스크린샷(1280×800)과 프로모션 타일은 가짜 넷플릭스 페이지에서 headless Chrome으로 다시 찍을 수 있습니다:

```bash
node dev/store-shots.mjs
```

올릴 zip(확장에 필요한 파일만):

```bash
zip -X store/shadowmate-$(node -p "require('./manifest.json').version").zip manifest.json lib.js content.js content.css bridge.js saved.html saved.js help.html icons/*.png
```

문제가 생기면 넷플릭스 탭의 개발자 도구 콘솔에서 `[dualsub]` 로그를 확인하세요.
